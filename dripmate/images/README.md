## 🚀 구글 플레이 콘솔 업로드 가이드

1. **Google Play Console** 로그인 후 **[드립메이트(DripMate)]** 앱 선택
2. 좌측 메뉴: **[성장(또는 사용자 늘리기)]** ➡️ **[스토어 등록정보]** ➡️ **[기본 스토어 등록정보]** 이동  
3. **'앱 아이콘'** (512×512) ➡️ `google_play_icon_512.png` 업로드
4. **'그래픽 이미지'** (1024×500) ➡️ `feature_graphic_1024x500.png` 업로드
5. **'휴대전화 스크린샷'** ➡️ `screenshot_01_smart_recipe.png`부터 `08_taste_report.png`까지 8장 순서대로 드래그 앤 드롭 업로드
6. 우측 하단 **[저장]** 클릭
